# Bulk Unpack storage handoff, October 19, 2026

Bulk Unpack now transfers eligible crate contents into the Shed or Closet at the current location. Use Place or Load Layout afterward to place them. A furnished house or guild hall retains its existing identity, permanent interior and furnishings.

Previously, the batch restored each member's old placed/stored state and tested the old world pose against the destination region. A relocated house could therefore be rejected even though it was valid for storage on the destination plot. The batch now selects by current estate type, item placement mask and allowed house definition. Capacity, permissions, creator/foreign-item restrictions, rent, member identity and revisions remain checked under the existing aggregate transaction. Extraction rechecks destination eligibility before removing membership. An explicit original-state restore through the server API retains its geometry check; bulk Unpack does not bypass placement validation, because it does not place items.

Successful bulk actions clear affected canceled previews and retain the existing complete estate/furniture refresh. No opcode, packet structure or database migration changed.

The original client's unpack confirmation describes items allowed at the current location. The [official House of Thule guide](https://www.everquest.com/news/imported-eq-enus-52047) distinguishes Shed/Closet storage from placement and describes crate-based moving. The [community moving guide](https://fanra.fandom.com/wiki/Player_housing#Moving_your_house) lists Unpack followed by loading a saved layout. These support this storage-first compatibility behavior; an authenticated May 2013 server capture has not established the exact historical server policy.

The zone build and 19 focused destination eligibility checks passed. One complete original-client cycle passed on a guild plot: Pack the furnished Standard Guild Hall, confirm Unpack, observe the empty crate and hall in Yard/Stored immediately, Load Yard to restore placement, and select normal Enter. The same permanent interior and original furniture were retained, with unchanged house binding, furniture payload and house assignment. Existing protected properties and items were unchanged. No zoning or relog was needed between Unpack and layout restoration. Private checks, screenshots, client XML and runtime data are excluded from this repository.
