# Returning belongings to multiple owners

This optional batch returns supported belongings to their original owners when a reviewed inactive property is released. It can create several moving crates, preserve a furnished house and its permanent room, and return supported room/vault objects directly to their rightful owners. It does not hand every contributor's belongings to the guild leader.

The full property is processed in one transaction across every recipient. All recipients must be offline with clear inventory/application barriers and enough ordinary saved-inventory slots. Crate content and capacity come from the reviewed catalogue, with at most one house per bin. Same-owner room objects stay attached to their house; foreign-owned room objects and supported vault objects return directly. A final immutable conservation seal records every source, disposition, generated crate and financial movement. Any late failure rolls back all recipients, ownership release and refund together.

The existing reviewed ninety-day personal or thirty-day current-roster guild inactivity authority remains required. New tables start empty; this feature activates no property automatically. For guild property, the reviewed current leader receives unused escrow, while other owners retain their belongings. No purchase-price refund, guild-bank debit or new client opcode is introduced. New generated-crate origin records distinguish recipient and bin without changing the creator later.

Guarded guild deletion can accept historical returned cargo only when its complete seal and current safe custody or genuine completed whole-item return prove settlement. Old occupied returns are not automatically certified. Corrupt or incomplete proofs still block deletion.
