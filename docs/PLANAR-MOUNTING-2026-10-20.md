# Source-bound planar mounting and recovered height-query libraries

The V5 mounted-region policy extends the prior oriented V4 policy to finite oblique source planes. This is a conservative emulator permission/collision policy derived from the matching original assets and client rules. It is not recovered Live permission-region data or complete native placement equivalence.

## Finite surfaces and collision

A trusted map query returns its actual stable triangle ID and source-side sign. Enrollment binds an explicit source-triangle inventory, per-triangle allowed sides, exact source count, original asset/map identities and source-ledger digest into a distinct V5 fingerprint. The ten registered interior families contain 72,581 reviewed structural terrain triangles in that inventory. Source polygon flags, winding and source-to-map correspondence were checked; decorative placed models and degenerate or mode-ineligible triangles are excluded. The installed Standard map was independently checked rather than substituted with a similar prepared map.

The source component must have exact coplanarity, consistent winding and positive-length shared edges. Exact rational projection and triangle-union subtraction prove the complete conservative oriented footprint. A hole or edge overhang remains unsupported. Only the proved source component is exempted from collision. Neighboring noncoplanar facets remain blockers, including facets belonging to the same curved mesh.

The inward connection to a current authenticated base permission box solves all three axis inequalities along the contacted normal. The complete translation is one swept zonotope, with explicit conversion-error enclosure and exact destination-fit proof. Body and corridor collision are separate required checks. There are no sampled intermediate positions, whole-mesh exemptions or guessed depth padding.

Immutable topology is shared across all seeds in the same component. The cache retains one copy of the reviewed inventory instead of copying a large whitelist for each clicked triangle. Contact side, current pose, finite footprint, collision, estate/ACL/session and content selection remain fresh. A source count or digest mismatch refuses the extension; missing or mismatched automatic inventory retains the prior V4 registration.

## Saved content

New Add operations can select V5. Existing V4/V3/V2/V1/base digests retain their original interpretations through the predecessor chain. No stored furnishing, catalog blob, ownership or inventory is migrated by this update. Return followed by a normal fresh Add selects the current reviewed policy.

## Recovered Floor/Ceiling libraries

The source overlay also includes separate pure geometry APIs: `original_sphere_query.h`, `original_sphere_source.h`, `original_actor_query_frame.h`, `original_renderer_box.h` and `placed_height_filters.h`, with their constant/operation includes. These are not connected to live placement admission in this update.

The bounded sphere/triangle implementation preserves the original face/edge/vertex calculations, nearest fraction, original normal, stopped-sphere pullback and floating-point state. The source adapter retains stable source IDs and refuses invalid sources, incomplete budgets and incompatible equal-time contacts. Original normals are never normalized or flipped by this API.

The frame helper keeps the scaled/rotated renderer center C, rotated half-extents E and minimum unrotated extent radius separate. Screen projection and vertical fallback have different stored operation chains. Floor uses its original additional 0.001 adjustment; Ceiling does not. The renderer-box helper reproduces the original angle conversion, x87 sine/cosine and eight-corner refit/store sequence, including rounding differences that an analytic rotated AABB omits. Its architecture-specific route refuses unsupported environments. Compile these original-arithmetic APIs with strict floating-point semantics: no fast math, contraction disabled and dynamic rounding enabled.

The recovered ordinary placed-context filters exclude self by identity and include other placed actors before the general volume/mask rules. Terrain flags and one-sided motion tests are distinct. Consequently a terrain-only trace cannot replace the original Floor/Ceiling scene query. Runtime integration still needs native terrain/actor scene transforms and complete current actor primitives/meshes, plus the original transient candidate-center height-query inputs. Those inputs are not fields in the commit packet. The recovered Floor extra-height argument is zero and the original display radius initializes to one; that does not supply the missing transient query center (the desired center after the outer collision/retry path, rather than the raw motion-query stop).

## Remaining limits

Locally planar facets of a curved mesh can be supported when the complete item footprint fits; placement spanning a noncoplanar bend is not enabled. Full native Floor/Ceiling source collection and nonzero-center acceptance remain unfinished. Existing point-ray admission is not relabeled as the recovered sphere solver. A captured unrotated box matches the recovered scale/cache path; arbitrary rotated renderer-box equivalence still needs a direct native witness. A new controlled hanging-item preview supplied matching original mesh/topology and cached box evidence, and its final pose has an exact compatible original Height fallback replay. The replay input was diagnostic, not a captured transient client input, so it is not installed as a guessed runtime default.

No opcode, wire struct, SQL migration or client asset change is required for V5. Deploy matching world, zone and inventory-recovery binaries from the same source snapshot. Original game assets and private evidence/fixtures are not included in this publication.

Separate genuine personal, Standard and Grand map checks covered finite support and neighboring blockers. These fixtures and their raw results remain private.

Native personal/Grand furnishing sessions and native placement on an oblique facet were not performed in this batch; those families and facets have actual-map geometry evidence.

Inventory runtime GUID columns differed across relogin; no GUID rewrite was used to force a byte-identical snapshot. The client was camped with no active inventory sessions, leases or pending operations.

This completes the V5 finite-planar extension and publication of the recovered pure query libraries. It does not complete full native Floor/Ceiling runtime admission or support spanning a noncoplanar curved bend.
